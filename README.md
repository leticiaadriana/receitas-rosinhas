# ✧˚.🍓⋆ Receitas Rosinhas ✧˚. 

####  Receitas Rosinhas é uma aplicação para guardar as minhas receitas preferidas e para me lembrar que eu amo cozinhar :)

### Sobre:

Receitas Rosinhas é um blog simples e intuitivo com design criativo, possuindo o objetivo de disponibilizar receitas doces e salgadas.

### Stack:
O projeto usa as seguintes linguagens e ferramentas:
- **React** – Framework baseado em componentes para construir interfaces responsivas 
- **JavaScript** – Linguagem de programação principal utilizada na aplicação 
- **Node.js** – Ambiente de execução de backend para processar a lógica do lado do servidor
- **MongoDB** – Base de dados utilizada para guardar e manipular os dados da aplicação
